# Guia de Contribuição — henry-8x-python

Agradecemos o interesse em contribuir com a biblioteca **henry-8x-python**!  
Este projeto é open-source e focado em fornecer uma integração Python simples, nativa e sem dependências externas para equipamentos da linha Henry 8X.

---

## 🚀 Como Contribuir

1. **Faça um Fork do repositório** no GitHub.
2. **Crie uma branch** com sua modificação:
   ```bash
   git checkout -b minha-feature
   ```
3. **Faça os ajustes ou adicione novos exemplos**.
4. **Envie um Pull Request (PR)** explicando detalhadamente o que foi adicionado ou corrigido.

---

## 🐛 Reportando Bugs ou Dúvidas

Se encontrou algum problema ou tem sugestões de melhoria no suporte a novos modelos da Henry:
- Abra uma **Issue** no GitHub detalhando o modelo do equipamento, comando testado e payload retornado.
